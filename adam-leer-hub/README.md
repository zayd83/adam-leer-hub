# Adams leer-hub

Leer-hub voor brugklas gymnasium: uitleg, oefenrondes, flitskaarten en oefentoetsen voor wiskunde, Nederlands, Engels, Frans, geschiedenis, aardrijkskunde en biologie.

Gewone HTML, CSS en JavaScript, zonder build-stap. Open `index.html` of zet de map op Vercel (Framework Preset: Other, build command leeg).

- `index.html`: de app (opmaak, game-laag, tools)
- `vakken/*.js`: de lesstof en vragen per vak
